##  Built With
- **Backend:** Node.js, Express.js
- **Templating Engine:** EJS (Embedded JavaScript Templates)
- **Styling:** Custom CSS (`public/Content/app.css`). This is the same CSS I used in Assignment 1 
  **Deployment**: Render (https://render.com/)

```text
Assignment-2/
├── public/  # Assets (CSS, images, client-side JS). The following public file was used to store any CSS, images,
 or  any script content so that it is organized nicely and can be found easily when needed 
├── routes/   # Express router modules (index.js, users.js). I used this route folder for  handling any requests that my
website receives, and it defines how it replies to them
├── views/  # EJS view templates (partials, home, about, projects, contact). The views basically store the EJS  templates and files
 that tend to render any HTML pages that are basically being displayed to the individual. 
├── app.js      # Express application setup & middleware
├── package.json  # Project dependencies & scripts
└── server.js   # Server entry point, what is basically does is that it helps my website to boot up online and tells the system about which port it should listen to.
```
